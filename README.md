# AutoFilter 3

> Archived prototype. Active development continues in [FilterVault](https://github.com/kongor-co/save-any-shop-filter).

This repository explored reusable personal shopping attributes, deterministic official mappings, user-created mappings, structural fingerprints, mapping health, and optional per-shop automation.

It is retained as design history. Its profile and personal-mapping concepts are documented as proposals in the canonical FilterVault repository. Do not start new implementation work here.
